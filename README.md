# 카드 내역 분석기 (household_budget)

카드사·은행에서 받은 CSV 내역서를 업로드하면, 브라우저 안에서만 분석해서
지출을 요약해주는 완전 오프라인 1페이지 웹앱입니다. 서버도, 네트워크 호출도 없습니다.

**바로 써보기 → <https://kyuradel.github.io/household_budget/>**

## 특징

- **100% 클라이언트 사이드** — 파싱·집계가 전부 이 브라우저 탭 안에서 실행되고, 어떤 서버로도 전송되지 않습니다. 탭을 닫으면 데이터는 남지 않습니다.
- **컬럼 자동 인식** — CSV 헤더를 보고 날짜·가맹점·금액 컬럼을 자동으로 찾습니다. 헤더가 애매하면 직접 매핑할 수 있는 화면이 뜹니다.
- **자동 카테고리 분류** — 업종/카테고리 컬럼이 없어도 가맹점명 키워드로 식비·교통·쇼핑 등으로 자동 분류합니다.
- **인코딩 자동 감지** — UTF-8 / EUC-KR(CP949) 둘 다 자동으로 읽습니다.
- **분석 결과** — 총 지출, 일 평균, 카테고리별·가맹점별·월별 지출, 고액 결제 TOP 10을 보여줍니다.
- **의존성 없음** — 외부 라이브러리·CDN·빌드 과정 없이 순수 HTML/CSS/JS로만 작성되었습니다.

## 로컬에서 실행하기

별도 설치 없이 `index.html`을 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다.

```bash
git clone https://github.com/kyuradel/household_budget.git
cd household_budget
# index.html을 브라우저로 열기
```

테스트용으로 `sample_card_statement.csv`가 포함되어 있어서, 바로 업로드해서 동작을 확인해볼 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 구조 |
| `style.css` | 스타일 (라이트/다크 모드 지원) |
| `app.js` | CSV 파싱, 분석 로직, 렌더링 |
| `sample_card_statement.csv` | 테스트용 샘플 내역서 |
